# AI and recording roles

OpenAI Codex generated the game concept, deterministic physics/scoring engine, UI and canvas artwork code, procedural oscillator sounds, tests, documentation and delivery text at the user's direction. Codex also reviewed real IntelliJ inspection findings and made the documented interface cleanups.

The user supplied the objective and authorization. The work is not described as independent human coding, independent human concept development, manual human IDE debugging or independent human gameplay.

## Browser operations and capture

During the demonstrated run, **Codex operated normal visible in-game controls through Chrome extension**: Play, Launch, Pause/Resume, the Angle and Power sliders, the next throw, natural result, and One more round. These were ordinary UI inputs, rather than changes to hidden game state.

The recording companion copied the actual game canvas and current visible DOM HUD text into a separate recording canvas. It did not play the game, modify the engine, inject a score or request a screen/microphone capture. The camera-free result is composed game footage, not a desktop recording.

## Edited demonstration

The final role-corrected r3 video is 87.50 seconds, H.264, 1280×720, with burned-in English captions and no audio. Its source run actually reached 300 points, two rings and two shots, then reset to zero and 45 seconds.

The edit omits twelve seconds of paused waiting and six seconds of result waiting, holds an actual captured reset frame for three seconds, and adds original title/tool/AI-role cards. The cuts and held frame are disclosed in the video. Normal frame-rate conversion duplicates/drops existing frames; it does not generate gameplay motion or scores.

The introduction and AI card explicitly identify Codex's browser UI operations. Any recorder-only non-control wording describes the capture helper, not a claim that the overall session was independently human-played.

## Tool distinction

IntelliJ IDEA 2026.3 performed real formatting and static analysis. Node executed the existing tests. No JetBrains AI, Junie or Air was used.

The shipped game has no model weights, AI runtime, external API or player-content upload. Its visual and sound assets are executable code, without generated raster assets or sampled music.
